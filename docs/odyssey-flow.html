What talks to what, in which direction, and over what. The beacon and the video downlink are one-way by design — neither can be told anything by the aircraft's peers, so neither can be used to reach it.

The state ladder escalate-only · §6

Not a state graph — a ratchet. The ten states are ranked by severity, and request() is honoured only if it moves to an equal or higher rank. There is exactly one way back down.

Why a ladder, and not a state graph

Revision 1.0 checked the state and then assigned it, from two cores, with no lock. A free-fall detection on the flight core could be overwritten by a failsafe-landing request on the telemetry core — and the result was all four motors spinning back up underneath an already-deployed canopy.

Ranking the states fixes it structurally rather than narrowing the window. FAILSAFE_LANDING is 7 and FREEFALL_PARACHUTE is 8, so the dangerous transition cannot happen however the two cores interleave. Every move is a single atomic test-and-set under a spinlock; the race is not made rarer, it is made harmless. That is finding 6.
