Ten Bytes Of Envelope

One frame format carries all four conversations — telemetry down, commands up, the AUX broadcast, and the beacon. Eight bytes of header, a payload, and a CRC that deliberately does not cover the first byte.

The CRC skips magic, on purpose

odyCrc16 is CRC-16/CCITT — polynomial 0x1021, initial 0xFFFF — and it covers version through the last payload byte. The start-of-frame byte is excluded so a receiver that has lost sync can hunt for 0xA7 without special-casing the checksum, and so a byte that arrives corrupted into 0xA7 still fails on CRC rather than on framing.

reserved is zero and exists only to keep the payload 4-byte aligned. It is a place to put a future field without moving anything.

Only one of these is bidirectional

Telemetry and commands share the LoRa link, so the ground station can talk back. The AUX broadcast is transmit-only — the flight controller never listens on it, so a faulty beacon or Remote ID module cannot feed data into the avionics or jam the line. And the beacon transmits to the ground on its own, from its own cell, after the aircraft is down.

Five opcodes, and none of them arms

The ground station can ask the aircraft to come home, to land now, or to answer a landing prompt. It cannot arm, and it cannot disarm in flight. Arming needs a physical button held for a second next to the aircraft (sheet 4), and the state ladder only escalates (sheet 3) — so no command on this link can make the aircraft less safe than it already is.
